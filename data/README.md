# Datasets



This folder contains information about the datasets used during the development of the Precision Farming Advisor project.



The original datasets are not included in this public repository.



\## Datasets Used



### 1\. Crop Recommendation Dataset



**Purpose:** 

Used for developing the Crop Recommendation module.



**Application:**  

The dataset contains agricultural and environmental parameters used to train a machine learning model for recommending suitable crops based on given soil and climatic conditions.



**Used In:**  

`notebooks/Crop\_Recommendation.ipynb`



\---



### 2\. India Agriculture Crop Production Dataset



**Purpose:**

Used for developing the Crop Yield Prediction module.



**Application:**  

The dataset was used for analyzing agricultural crop production data and developing a machine learning model for crop yield prediction.



**Used In:**  

`notebooks/Crop\_Yield\_Prediction.ipynb`



\---



### 3\. Fertilizer Dataset



**Purpose:**  

Used for the Fertilizer Recommendation module.



**Application:**  

The dataset provides crop-specific nutrient requirements that are used by the rule-based recommendation system to identify nutrient deficiencies or excesses and provide fertilizer recommendations.



**Used In:**  

`application/main.py`



\---



#### Note:



The raw datasets are not included in this repository. They were used during the development and training of the project models.
