Welcome to **Precision Farming Advisor** - where farming meets the future! 🌾

Precision Farming Advisor is a multi-module agricultural decision-support system that applies machine learning, deep learning, and rule-based recommendations to assist farmers with crop selection, plant disease identification, crop yield forecasting, and fertilizer recommendations.

The project combines predictive analytics with agricultural data to support more informed and data-driven farming decisions.


## The Key Features

### Crop Recommendation

- 🤖 Uses machine learning to recommend suitable crops.
- 🧐 Provides crop recommendations based on soil and climatic conditions.
- 📊 The model delivers strong predictive performance for crop recommendation.

### Plant Disease Prediction

- 🌿 Uses deep learning with InceptionV3 for image-based plant disease classification.
- 📸 Upload a plant image to identify potential diseases.

### Crop Yield Prediction

- 📈 Predicts future crop yields using machine learning.
- 🧮 Uses XGBoost to provide strong predictive performance for crop yield forecasting.
- 🌡️ Incorporates agricultural and environmental factors for yield prediction.

### Fertilizer Recommendation

- 🌱 Provides fertilizer recommendations based on crop and soil nutrient information.
- 🌿 Uses a rule-based approach based on Nitrogen (N), Phosphorus (P), and Potassium (K) levels.
- 📊 Identifies nutrient deficiencies or excesses and provides targeted recommendations.
